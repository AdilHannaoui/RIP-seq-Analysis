# RIP-seq Analysis Pipeline for Rpb4 Mutants in Saccharomyces cerevisiae

## Overview
<p align="justify">
This repository contains a complete RIP-seq analysis pipeline applied to Saccharomyces cerevisiae strains carrying mutations in the Rpb4 subunit of RNA polymerase II.

The analysis covers:
* Quality control of raw FASTQ files
* Read alignment and quantification
* Differential expression analysis
* Peak Calling analysis
* TSS Windows analysis
* Downstream statistical analysis and visualization
<br>

<br>
The objective of this project is to characterize RNA binding sites associated with phospho-null mutations in the Rpb4 subunit.

## Repository structure

```text
├── run_pipeline.sh
├── environment.yml
├── download_genome.sh
├── download_test_data.sh

├── R/                     Statistical analysis scripts (DESeq2, enrichment, plots)
```

## Requirements

- Conda/Mamba (>= 4.10)
- GNU Parallel

- CPU: ≥ 8 cores (recommended 10-16)

### Quick Start

1. **Clone repository**
```bash
git clone https://github.com/AdilHannaoui/RIP-seq-Analysis
cd RIP-seq-Analysis
```

2. **Create environment**
```bash
# Using mamba (recommended)
mamba env create -f environment.yml

# Or using conda
conda env create -f environment.yml
```

3. **Download reference genome**
```bash
chmod +x download_genome.sh
bash download_genome.sh
```

4. **Build HISAT2 index**
```bash
conda activate ripseq-rpb4
bowtie2-build reference/Saccharomyces_cerevisiae.R64-1-1.dna.toplevel.fa reference/sc_bt2_index
```

5. **Download Test data**
```bash
chmod +x download_test_data.sh
bash download_test_data.sh
```

6. **Run pipeline**
```bash
bash run_pipeline.sh
```

## Installation and running the pipeline
The ```run_pipeline.sh``` script orchestrates all preprocessing, alignment, quantification, and downstream R analyses in a single command.

All analyses are fully reproducible using the Conda environment defined in ```environment.yml```.

### Recommended: install ```mamba``` for faster environment creation
Creating environments that include R + Bioconductor can be slow with the default Conda solver. For a much faster and smoother installation, it is recommended to install mamba in the base environment

```conda install -n base mamba```

then create the environment using:

```
mamba env create -f environment.yml
```

If you prefer to use Conda:

```
conda env create -f environment.yml
```

Activate the environment

```
conda activate ripseq-rpb4
```

Before running the pipeline, ensure execution permissions:

```
chmod +x run_pipeline.sh
chmod +x bash/*.sh
```

Run the full workflow with:

```
bash run_pipeline.sh
```


## Inputs and Outputs

Inputs:
* FASTQ (test data included)
* FASTA (```ftp.ensembl.org/pub/release-112/fasta/saccharomyces_cerevisiae/dna/Saccharomyces_cerevisiae.R64-1-1.dna.toplevel.fa.gz```)
* GTF File (```ftp.ensembl.org/pub/release-112/gtf/saccharomyces_cerevisiae/Saccharomyces_cerevisiae.R64-1-1.112.gtf.gz```)
* configuration files (```R/config.R``` and ```bash/config.sh```)
* 
The Bowtie2 index must be generated from the provided FASTA before running the alignment step. The Path is defined in ```bash/config.sh```

Outputs:
* QC reports (```bash/01-fastqc.sh```)
* trimmed FASTQ (```bash/02-trimming.sh```)
* BAM (```bash/03-alignment_bowtie2.sh```)
* count matrix (```bash/04-featurecounts.sh```)
* peak files (```bash/05-peak_calling_exploratory.sh```  ```bash/06-peak_intersection_exploratory.sh```)
* TSS files (```bash/08-tss_metagene.sh```)
* DESeq2 tables (```R/02-deseq2_analysis.R```  ```R/02.1-deseq2_peaks_analysis.R```)
* integrated genes (```R/03-integrate_genes.R```)
* enrichment analysis (```R/04-enrichment_analysis.R```)
* Figures (```R/05-visualizations.R```)

## Experimental design

- Organism: Saccharomyces cerevisiae
- Conditions:
  - WT (n = 6)
  - Rpb4-S/T-A (n = 6)
  - Rpb4- (n = 6)
- Data type: RNA-seq (Single End)

Biological replicates were used for all conditions.
